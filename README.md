Sales Dashboard

📊 Project Overview

This project is an interactive Sales Analytics Dashboard built using Python, SQL, and Power BI.

The dashboard analyzes sales performance, product performance, customer types, promotions, regions, returns, discounts, and operational metrics.

🛠️ Tools & Technologies

- Python / Pandas — Data cleaning and preparation
- SQL — Data analysis and querying
- Power BI — Data visualization and dashboard development

📈 Sales Dashboard

The main dashboard includes:

- Sales by Product & Quantity — Parameter-based bar chart
- Sales by Customer Type — Pie chart
- Sales by Promotion — Donut chart
- Sales Over Period — Line chart
- Sales by Location & Region — Stacked area chart
- Total Orders — KPI card
- Total Days — KPI card
- Total Sales — KPI card
- Total Revenue — KPI card
- Time Slicer — Interactive time-based filtering
- Product Drill-through — Detailed product-level analysis

🔎 Product Drill-through

The product drill-through page provides detailed insights for the selected product.

Key Metrics

- Product Name
- Total Units
- Average Unit Price
- Average Shipping Cost
- Average Delivery Days

Visualizations

- Return Rate by Region
- Average Discount — Gauge
- Returned Orders — Pie chart
- Sales by Manager & Salesman — Clustered column chart
- Orders by Payment Method — Treemap

📐 Key Measures

The dashboard includes the following custom measures:

- Return Rate
- Total Quantity
- Total Sales

🎯 Project Objectives

- Analyze overall sales performance
- Identify product and regional sales trends
- Compare customer types and promotional performance
- Monitor returns and discounts
- Analyze payment methods and sales personnel performance
- Provide detailed product-level insights
- Build an interactive dashboard for business analysis
